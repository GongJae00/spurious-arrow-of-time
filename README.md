# Spurious Arrow of Time

Code for

**A Cue-Locality Audit Framework for Attributing Spurious Temporal Shortcuts in Deep Sequence Models**

YoungJae Cho, Do-Yup Kim, Youngjun Kim, Dae-Yeol Kim

High IID accuracy does not identify which temporal cue a sequence model uses. A directional cue can be generated by a temporal process and still be readable from a single frame; an out-of-distribution (OOD) score cannot tell that apart from genuine order dependence. This repository is the six-gate cue-locality audit and the companion generator family.

## Install

```bash
pip install -e ".[dev]"
```

## Generator

Each sequence mixes a task-causal core with a non-causal nuisance.

- Core: a hidden horizontal or vertical two-pixel source on a 16x16 grid, evolved by isotropic four-neighbor diffusion (alpha 0.22, L = 8).
- Label: source orientation.
- Nuisance: a moving pulse whose direction aligns with the label at train/IID (correlation 0.97) and is reversed under OOD (correlation 0.03).
- Observation: two channels, endpoint-matched so the last frame does not leak the direction.

Five named configurations:

| Config | Nuisance locality | Role |
|---|---|---|
| OE-Strict | order-encoded closed path | primary result |
| Trail-FL | frame-local trail residue | reclassified cue |
| Set-MF | order-invariant multi-frame | spectrum control |
| MF-Core | order-encoded, harder core | multi-frame core |
| OE-Core | both cues order-encoded | equalization control |

The sequence model is a per-frame CNN encoder plus a GRU, trained by ERM (AdamW, hidden size 64, 40 epochs, patience 12).

## Reproduce

Numbers in the paper come from the logged artifacts under `results/extended/`.

```bash
# OE-Strict (primary, 30 seeds)
python -m src.eval.hardpair_oe --seeds 30 --out results/extended/hardpair_oe30.json

# Trail-FL canonical (30 seeds)
python -m src.train.main_experiment \
  --config configs/irreversible_source_extended.yaml \
  --profile main_canonical \
  --out results/extended/main_canonical

# Simple order-encoded (30 seeds)
python -m src.train.main_experiment \
  --config configs/irreversible_source_extended.yaml \
  --profile oe_canonical \
  --out results/extended/oe_canonical

# Smoke check
bash experiments/smoke_benchmark.sh

python -m pytest -q
```

Sweeps, architecture controls, semi-synthetic transfer, and graph/video extensions are the remaining profiles in `configs/irreversible_source_extended.yaml` and the scripts in `src/eval/`.
